# 组件规范 · 编程课程作业提交与互评系统

> 与 `mock.css` 一一对应，后续 Vue 3 + Element Plus 实现时按本规范覆写主题变量，不另起一套。
> 单位 px；颜色取 `design-system.md`。

## 1. 按钮

| 类型 | 类名 | 背景 / 描边 / 文字 | 尺寸（高 × 内边距 × 字号） |
|---|---|---|---|
| 主按钮 | `.btn.primary` | `#1E4B3F` / 同色 / `#FFF` | 34 × 14 × 13 |
| 次按钮 | `.btn` | `#FFF` / `#DEE4E9` / `#1F2933` | 34 × 14 × 13 |
| 幽灵 | `.btn.ghost` | `#E8F0EC` / `#C8DBD2` / `#1E4B3F` | 34 × 14 × 13 |
| 危险 | `.btn.danger` | `#FFF` / `#E5C3C7` / `#B02A37` | 34 × 14 × 13 |
| 强调 | `.btn.gold` | `#C2703A` / 同色 / `#FFF` | 34 × 14 × 13 |
| 小号 | `.btn.sm` | 同上 | 26 × 10 × 12 |

- 圆角 6；hover 仅加深 6%（不做位移）；禁用态 `opacity: .5` + `cursor: not-allowed`
- 一屏内主按钮最多 1 个，位置固定在页面头部右侧或表单底部右侧
- 危险操作（撤回作业、确认抄袭、删除）必须二次确认，确认框内复述单据编号
- 行内操作最多「查看 + 1 个高频」，其余收进「更多」

## 2. 表单

- 行内筛选：`input` 高 34、圆角 6、边框 `#DEE4E9`；搜索框宽 220、下拉宽 200、日期 150
- 表单网格 `.fgrid`：两列，列间距 20，行间距 12；标签宽 96、右对齐、行高 34 对齐输入
- 全宽项用 `.it.full`（题目描述、评语等）
- 文本域：最小高 90，评语框 112，题目描述 132
- 聚焦态：边框 `#3D7A66` + `box-shadow: 0 0 0 3px rgba(61,122,102,.14)`
- 校验提示在字段下方，12px `#B02A37`，不弹 toast
- 滑块（互评打分三维度）：轨道高 6、圆点 16、右侧分值 15px 加粗 + 单位 11px；分量上限写死在标签下方（0–60 / 0–25 / 0–15）

## 3. 表格

- 表头：背景 `#F1F4F3`、字 13 `#5B6770`、内边距 9×12、下边框 1px
- 单元格：内边距 9×12、行线 `#EDF0F3`、hover 行底色 `#F8FAF9`
- **表头不设固定宽度**，全部由内容撑开；仅「操作」列可 `nowrap`
- 编号 / 学号 / 单号列使用等宽字体 12px
- 行内展开（结果登记）：`.expand` 行底色 `#F6FAF8`，内部四段式布局「编译结果 / 通过数 / 错误摘要 / 操作」，列宽 150 / 130 / 1fr / 120
- 超过 12 列时优先合并语义相近列，不做横向滚动条

## 4. 卡片

- 白底、1px `#DEE4E9`、圆角 8、内边距 16×18（看板卡片 11×14）
- 标题 15/22 600，副信息 11 `#5B6770`，标题与内容间距 12
- 看板卡片 `.dash .c` 固定行高、`overflow:hidden`，保证一屏；图表区 `.cbody` 必须 `flex:1;min-height:0`

## 5. 标签 / 状态

- 圆角 4、内边距 1×7、字号 12、行高 19，`white-space:nowrap`
- 颜色见 design-system 状态表；**必须同时带中文**，不允许只有色块
- 关键状态（待复核、低可信、超时未评）可加前置圆点或图标，仍保留文字

## 6. 弹窗 / 抽屉

- 抽屉宽 460（常规）、640（代码对比），右侧滑入，`z-index:20`，遮罩 `rgba(23,34,44,.26)` 在 `z-index:10`
- 抽屉顶部：单据编号 + 状态标签；中部：摘要字段（键值列表）；底部：操作按钮右对齐
- 审批 / 流转 / 指派一律走抽屉，不新开页面
- 抽屉内代码对比：两列等宽、行号对齐、命中行同色高亮

## 7. 分页

- 右对齐，`共 N 条 · 每页 M 条` + 页码 + 下一页
- 当前页：深绿底白字；其余白底描边
- 后端分页，前端保留页码与每页条数（10 / 20 / 50）

## 8. 图表

| 图表 | 用途 | 规格 |
|---|---|---|
| 分组双柱 | 提交率 vs 迟交率、平均分 vs 标准差 | 柱宽 14，双柱间距 4，类目间距 14 |
| 竖柱图 | 用例通过数分布、分数段人数 | 柱宽 ≤ 32，标签 10px 不换行，超过 5 类先缩名 |
| 横向条形 | 相似度区间、各班平均分 | 名称列 68–108 右对齐，数值列 46 |
| 环形 | 成绩分段、可信度等级 | 直径 118–126，环宽 13，中心放主数值 + 单位 |
| 折线 | 近 7 天互评完成趋势 | 2px 线宽，圆点 r2.4 白心，末位标签右对齐防裁切 |
| 散点 | 互评总分 vs 教师评分 | r3.4，`fill-opacity .68`，viewBox 宽度按卡片真实像素设 |
| 堆叠柱 | 可信度等级按作业/班级占比 | 条高 16，段间无间隙，右侧给百分比 |

所有图表容器高度由卡片行高决定，不在图表内部写死高度；空数据时显示「暂无数据」占位而非空白。

## 9. 代码相关组件

| 组件 | 说明 |
|---|---|
| `.code` 代码块 | 行号列 40px、正文 12/20、浅底 `#FBFCFC`；高度档位 120–420 |
| `.code-head` | 文件名（等宽）+ 徽标（行数 / 大小）+ 右侧操作（上传、格式化） |
| `.cmp` 并排对比 | 两列 `1fr 1fr`，列头写提交号 + 时间，行高 19 对齐 |
| `.sim-line` | 证据片段单行，命中行左 2px 橙条 + `#FCF3E8` 底 |
| 提交页 | 左 44% 题目描述 + 用例表，右代码编辑器 + 提交记录，不换页 |

## 10. 空状态与加载

- 空状态：图标 + 一句原因 + 一个下一步按钮（例：「本作业尚无提交 — 截止后自动进入互评」）
- 加载超过 300ms 显示局部骨架，禁止整页白屏
- 列表请求失败：行内提示 + 重试按钮，不用全局弹窗

## 11. 移动端（< 768px）

- 侧栏改抽屉，筛选折叠为底部面板，主按钮固定安全区
- 表格改信息卡片：只留编号 / 状态 / 时间 / 负责人，点击进详情
- 点击区域 ≥ 44px；底部固定操作区不得遮挡分页
- 优先支持：查作业、提交、互评打分、看成绩、看消息；复杂统计保留桌面端
