# 设计系统 · 编程课程作业提交与互评系统

> 设计方向来自需求文档第 10 节：**工程工具风格**。深墨绿主色、等宽字体承载代码、左右分栏为主、代码区浅底保留行号。
> 视觉目标不是「教学管理系统」的蓝白模板，而是贴近 IDE / 代码评审工具的工作台气质：信息密度高、边界用细线而非阴影、状态一律配中文标签。

## 1. 色彩

| 用途 | 色值 | 使用说明 |
|---|---|---|
| 主色 | `#1E4B3F` | 侧栏底色、主按钮、当前菜单、关键数字、图表主系列 |
| 辅助色 | `#3D7A66` | 次级按钮、筛选选中态、普通图表系列、进度条 |
| 强调色 | `#C2703A` | 重点提示、待办数量、对比图表第二系列、迟交/超时 |
| 页面背景 | `#F5F6F7` | 内容区背景 |
| 容器 | `#FFFFFF` | 表格、表单、卡片 |
| 正文 | `#1F2933` | 标题与正文 |
| 次要文字 | `#5B6770` | 说明、表头、时间 |
| 分隔线 | `#DEE4E9` | 卡片边框、表格行线 |
| 成功 | `#2B7955` | 已通过、已评、已发布 |
| 危险 | `#B02A37` | 编译失败、确认抄袭、超时未评（只做小面积） |
| 状态底 | 见下表 | 标签底色统一为 6%–10% 透明度的同色系 |

状态标签配色（必须「色 + 中文」双通道，不能只靠颜色）：

| 状态组 | 取值 | 标签样式 |
|---|---|---|
| 作业 | 草稿 / 已撤回 | `t-gray` 底 `#EDF0F3` 字 `#5B6A76` |
| 作业 | 已发布 / 提交中 | `t-blue` 底 `#E7F0EC` 字 `#1E4B3F` |
| 作业 | 互评中 / 评分中 | `t-amber` 底 `#FBEDE1` 字 `#9C5C12` |
| 作业 | 已归档 | `t-green` 底 `#E3F0E9` 字 `#2B7955` |
| 提交 | 待登记 | `t-gray` |
| 提交 | 已登记 / 已评分 | `t-blue` / `t-green` |
| 互评任务 | 待评 / 已评 / 超时未评 | `t-amber` / `t-green` / `t-red` |
| 查重 | 待复核 / 确认抄袭 / 误报 / 需面谈 | `t-amber` / `t-red` / `t-green` / `t-blue` |
| 申诉 | 待受理 / 处理中 / 已改分 / 已驳回 | `t-amber` / `t-blue` / `t-green` / `t-gray` |
| 可信度 | 高 / 中 / 较低 / 低 | `t-green` / `t-blue` / `t-amber` / `t-red` |

图表取色顺序：`#1E4B3F` → `#3D7A66` → `#C2703A` → `#A9B7B0` → `#B02A37`。同一含义跨页面必须同色（例如「高可信」永远是 `#1E4B3F`）。

## 2. 字体

- 界面字体：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 代码字体：`"SF Mono", Menlo, Consolas, "Courier New", monospace`（仅用于代码块、编号、学号、业务单号）
- 字号阶梯：

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 20 / 28 | 600 | 页面标题 |
| H2 | 15 / 22 | 600 | 卡片标题 |
| 正文 | 14 / 22 | 400 | 默认 |
| 表格 / 表单 | 13 / 21 | 400 | 列表与录入 |
| 辅助 | 12 / 19 | 400 | 说明、表头、时间 |
| 微 | 11 / 16 | 400 | 图表轴、标签内文字 |
| 指标数字 | 25 / 32 | 600 | KPI（`font-variant-numeric: tabular-nums`） |
| 代码 | 12 / 20 | 400 | 带行号的代码区 |

数字一律 `tabular-nums`，避免表格列抖动。

## 3. 间距与栅格

- 桌面端：`220px` 侧栏 + `56px` 顶栏 + 自适应内容区；内容区 `padding: 24px`
- 间距基数 4，常用 8 / 12 / 14 / 16 / 24
- 卡片间距 12（看板）、14（普通页）
- 表单标签宽 96–110，输入宽自适应（单列 360–520），筛选下拉 200，搜索框 220
- 看板页用 `.dash`：4 列网格，`grid-auto-rows` 按实测固定（1440×900 下 305px × 2 行 = 一屏），卡片内 `overflow:hidden` 保证不撑破

## 4. 圆角 / 描边 / 阴影

- 圆角：6（按钮、输入）、8（卡片、代码区）、12（状态胶囊）、50%（头像）
- 描边：所有容器 1px `#DEE4E9`；不用阴影做层次
- 阴影仅用于浮层：抽屉 `-8px 0 24px rgba(23,34,44,.14)`，遮罩 `rgba(23,34,44,.26)`
- 左侧 3px 色条用于「当前选中」与「风险提示」（`.wcard.hot`）

## 5. 代码区规范（本系统特有）

- 浅色底 `#FBFCFC`，行号列底色 `#F2F5F4`、字色 `#A8B4AE`、右对齐，不可选中
- 命中/差异行：底色 `#FCF3E8` + 行号列 `#F7E8D6`，靠底色而非加粗表达
- 语法着色：关键字 `#7A3E8C`、字符串 `#2B7955`、注释 `#8FA099` 斜体、数字 `#B0622A`、方法名 `#1E4B3F`
- 代码区高度档位：120 / 150 / 180 / 240 / 300 / 360 / 420，按页面留白选，不做自适应拉伸
- 并排对比（查重复核）：两列等宽，行高严格一致（19px），保证同一行号对齐

## 6. 角色视觉区分

同一系统五个角色，靠侧栏底色深浅 + 首页形态区分，不换主题色：

| 角色 | 侧栏底色 | 首页形态 |
|---|---|---|
| 任课教师 | `#1E4B3F`（主色） | 后台管理（看板 + 图表） |
| 助教 | `#24564A` | 后台管理（批改工作台优先） |
| 教务管理员 | `#1A3B33` | 后台管理（统计为主） |
| 系统管理员 | `#142C26` | 后台管理（配置为主） |
| 学生 | 无侧栏 | 门户（顶部导航 + 内容流） |

学生端不出现侧栏，避免「学生也像管理员」；移动端 390 宽原型见 `28-mobile.html`。

## 7. 一屏约束

- 看板页（`02-dash`、`29-stats`）：1440×900 内 `content.scrollHeight === 844`，不出现纵向滚动
- 内容型详情页（作业详情、可信度明细、计算留痕、菜单配置）允许纵向滚动，但首屏必须能看到主表或主结论
- 所有页面 `scrollWidth === 1440`，不出现横向滚动
